# Lab04: Genetic Search

Консольная программа на C#: читает базу белков и список команд, выполняет команды
(`search`, `diff`, `mode`) и записывает результат в `genedata.txt`.

## Входные файлы

- `sequences.txt` — одна строка = один белок: `название<TAB>организм<TAB>цепочка аминокислот`.
  Цепочка может быть сжата алгоритмом RLE (`AAAAAAAATA` -> `8ATA`).
- `commands.txt` — одна строка = одна команда:
  - `search<TAB>фрагмент` — найти белки, цепочка которых содержит фрагмент;
  - `diff<TAB>белок1<TAB>белок2` — число позиций, в которых цепочки различаются;
  - `mode<TAB>белок` — самая частая аминокислота и сколько раз она встречается.

## Запуск

Файлы с данными должны лежать рядом с исполняемым файлом (или передайте пути аргументами):

```
GeneticSearch.exe sequences.0.txt commands.0.txt genedata.txt
```

Без аргументов используются `sequences.0.txt`, `commands.0.txt` и `genedata.txt`.

## Устройство программы (Program.cs)

| Часть | Что делает |
|---|---|
| `struct Protein`, `struct Command` | хранят данные белка и команды |
| `ReadData`, `ReadCommands` | читают файлы в списки структур; цепочки сразу распаковываются |
| `RLEncoding`, `RLDecoding` | сжатие и распаковка RLE |
| `CommandHandler` | идёт по командам и вызывает нужный метод |
| `Search`, `Diff`, `Mode` | выполняют операции и пишут результат в файл |
| `Main` | задаёт имена файлов, открывает выходной файл, запускает обработку |
